Session 5 quirks — the six things to remember

1
Alembic must reach head from an empty DB. Fresh Cloud SQL instances have no db/init.sql run. The migration Job assumes tables created there already exist. Workaround: one-off bootstrap Job (see docs/staging_access.md §6). Permanent fix: TODO P0.1 — baseline migration.
2
PAT must allow submodule access. CROSS_REPO_PAT (fine-grained) needs Contents: Read on all three repos: jackpot-backend, jackpot-nf, jackpot-schema. Never cross-paste with Google OAuth secrets (GOCSPX- prefix is NOT a GitHub PAT). See CLAUDE.md Rule 45.
3
COPY nf/ required in the image. Dockerfile.api must include nf/ so backend/routers/pipelines.py can import RESULT_SCHEMAS. Without it, the whole FastAPI app crashes at startup with ModuleNotFoundError.
4
sys.path hack is fragile. pipelines.py does sys.path.insert(0, "/app/nf") at import time. Any tool that evaluates the router without nf/ available (linting, tests) breaks. Permanent fix: TODO P0.3 — move RESULT_SCHEMAS into the backend package.
5
No public URL yet. Smoke test uses kubectl port-forward. Google OAuth flow can't be tested end-to-end until Ingress + DNS + managed cert land. TODO P1.3.
6
Helm --wait timeouts wedge the release. If helm upgrade --wait --timeout 10m hits its timeout, the release sits at pending-upgrade forever, blocking all subsequent deploys. Recovery: helm rollback <release> <last-good-rev>. TODO P1.4 — evaluate --atomic.
